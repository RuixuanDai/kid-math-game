# 🦁 童趣数学小王国 (Math Kingdom - 高阶益智挑战版)

专为 **6岁幼小衔接高阶儿童** 量身定制的全新升级版趣味数学游戏。遵循新加坡数学与蒙特梭利教学法，从“**实物点数**”跨越到“**结构化心算、空间几何与逻辑推理**”，助力孩子建立扎实的小学一年级数理基础！

---

## 🌟 核心升级与高阶亮点

1. **8 大综合素养关卡**：
   - 涵盖：**群计数、算式比大小、进退位加减与未知数填空、数字跳数找规律、十格阵凑十破十、认识指针时钟、3D等轴测空间积木、60秒极速冲刺**！
2. **三大进阶难度自由调节**：
   - **10以内基础**：巩固基础概念与点数。
   - **20以内进退位（默认推荐）**：突破 20 以内进位加法（凑十法）、退位减法（破十法）、半点时钟、多层积木。
   - **100以内挑战**：整十数加减、两位数倒置对比、三数连加连减、阶梯规律。
3. **空间积木“透视眼”模式**：
   - 提供 3D 积木的 **透视检验功能**，帮助孩子观察被遮挡的下层承重积木，突破幼小衔接空间想象难点。
4. **60秒极速冲刺挑战**：
   - 带有倒计时音效、得分与连对加成（🔥 3连对2倍星，5连对3倍星！），答题更刺激，培养快速心算与反应力。
5. **幸运扭蛋机与创意贴纸乐园**：
   - 答对获取小金星，抽取 12 款超萌角色贴纸；
   - 收集到的贴纸不仅能在图鉴中发声跳舞，还可以在“创意乐园”中自由拖拽排布、搭建专属动物公园！

## 🎮 8大益智关卡总览

| 关卡名称 | 培养目标 | 核心特色与玩法 |
| :--- | :--- | :--- |
| **🍓 森林数一数** | 一一对应 & 群计数 | 支持单个实物点数（标出1, 2, 3..），以及**“2个一组”、“5个一组”**群计数（乘法前置启蒙）。 |
| **⚖️ 天平比大小** | 算式对比 & 数位逆向 | 不仅对比单个数值，更对比**算式与数值**（如 `8 + 6` vs `15`），以及易混淆的**倒置两位数**（如 `47` vs `74`）。 |
| **🍩 趣味加减法** | 进退位 & 逆向求未知数 | 覆盖凑十法进位、破十法退位，以及**填空未知数**（如 `8 + [ ? ] = 14`）、三数连加连减。 |
| **🚂 规律小火车** | 数字跳跃与阶梯推理 | 包含双数跳数（`2, 4, 6, 8, [?]`）、5的倍数（`5, 10, 15, [?]`）、倒数与步长规律。 |
| **🧪 十格阵凑十** | 结构化数感（新加坡数学） | 国际公认的 2×5 十格阵模型，动态直观呈现**“把几拆成几和几来凑成10”**的思维全过程。 |
| **⏰ 奇妙时钟岛** | 生活时间认知 | 真实模拟指针时钟（蓝色短时针、红色长分针），考察**整点**（如 3:00）与**半点**（如 7:30）认知。 |
| **🧩 空间数积木** | 三维立体与遮挡推理 | 3D 等轴测木块搭建，要求孩子推算包括**被压在下层的隐藏积木**在内的总数，支持一键**透视验证**。 |
| **⚡ 60秒冲刺** | 极限反应与快速心算 | 60秒倒计时快速抢答，连对触发连击加成与音效爆发，挑战“数学小神童”最高勋章！ |
